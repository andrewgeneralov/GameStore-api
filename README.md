# GameStore API

## О проекте
GameStore API — RESTful API сервис для управления каталогом видеоигр, разработчиками и заказами.

### Основные возможности:
* Управление разработчиками и заказами
* Фильтрация игр по параметрам GET-запроса (`genre`, `developer`, `is_available`)
* Выполнение массовых операций (создание, обновление и удаление группы объектов)
* Интерактивная документация Swagger UI

---

## Модели данных

### 1. `Developer` (Разработчик)
* `id` — Уникальный идентификатор
* `name` — Название студии
* `country` — Страна
* `website` — Сайт
* `established_year` — Год основания

### 2. `Game` (Видеоигра)
* `id` — Уникальный идентификатор
* `title` — Название
* `description` — Описание
* `genre` — Жанр (`action`, `rpg`, `strategy`, `sports`, `simulation`)
* `price` — Стоимость
* `release_date` — Дата выхода
* `developer` — Внешний ключ на `Developer`
* `is_available` — Доступность (`true`/`false`)

### 3. `Order` (Заказ)
* `id` — Уникальный идентификатор
* `customer_email` — Email клиента
* `game` — Внешний ключ на `Game`
* `order_date` — Дата заказа
* `status` — Статус (`pending`, `completed`, `cancelled`)
* `quantity` — Количество

## Эндпоинты API (`/api/v1/games/`)

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/games/{id}/` | Получение данных об одном ресурсе |
| `GET` | `/api/v1/games/?genre=rpg` | Получение группы ресурсов с фильтрацией |
| `POST` | `/api/v1/games/` | Создание одного ресурса (передается JSON-объект) |
| `POST` | `/api/v1/games/` | Создание группы ресурсов (передается JSON-массив) |
| `PATCH` | `/api/v1/games/{id}/` | Обновление одного ресурса |
| `PATCH` | `/api/v1/games/` | Обновление группы ресурсов (JSON-массив объектов с `id`) |
| `DELETE` | `/api/v1/games/{id}/` | Удаление одного ресурса |
| `DELETE` | `/api/v1/games/` | Удаление группы ресурсов (JSON `{"ids": [1, 2]}`) |

**Документация Swagger UI:** `http://127.0.0.1:8000/api/docs/`
